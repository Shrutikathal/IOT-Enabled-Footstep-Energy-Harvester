# IoT-Enabled Footstep Energy Harvester

## 📌 Project Overview

The **IoT-Enabled Footstep Energy Harvester** is a project that demonstrates the conversion of mechanical energy generated by human footsteps into electrical energy using **piezoelectric sensors**.

The system captures pressure from footsteps, converts the generated AC voltage into DC using a bridge rectifier, smooths the output using a capacitor, and processes the signal using an **Arduino Uno**. The system also provides **real-time monitoring of generated voltage and footstep count through a 16×2 LCD display**.

The project is designed with future IoT expansion in mind, allowing modules such as **ESP8266/NodeMCU** to be integrated for remote monitoring and cloud-based analytics.

## 🎯 Objectives

- Convert mechanical energy from human footsteps into electrical energy.
- Use multiple piezoelectric sensors to improve energy generation.
- Convert the generated AC voltage into DC.
- Store and stabilize the generated electrical energy.
- Measure the generated voltage using Arduino.
- Detect and count footsteps using voltage spikes.
- Display voltage and footstep count in real time.
- Provide a foundation for future IoT-based monitoring and analytics.

## ⚙️ Working Principle

The system works through the following stages:

1. **Footstep Pressure**
   - Pressure is applied to the piezoelectric sensors placed beneath the footstep platform.

2. **Energy Generation**
   - The piezoelectric sensors generate a small AC voltage when mechanical pressure is applied.

3. **Rectification**
   - A full-bridge rectifier using **1N4007 diodes** converts the generated AC voltage into DC.

4. **Voltage Smoothing**
   - A capacitor is used to smooth fluctuations in the rectified output.

5. **Voltage Measurement**
   - A voltage divider is used to provide a safe measurable signal to the Arduino analog input.

6. **Processing**
   - Arduino reads the voltage, detects voltage spikes caused by footsteps, and maintains the footstep count.

7. **Real-Time Display**
   - A 16×2 LCD displays the generated voltage and total footstep count.

## ⚠️ Limitations

- Piezoelectric sensors generate relatively low electrical power.
- Voltage output varies depending on applied pressure.
- Energy losses occur during rectification.
- The prototype is intended for demonstration and low-power applications.
- Footstep detection based on voltage spikes may produce occasional false triggers.
- The basic prototype does not include a fully integrated IoT module.

## 🚀 Future Scope
